# Holophone 3.1.2 — Branding VSNT définitif

## Objet

Cette release intègre l'identité visuelle définitive de **VSim NeuroTek (VSNT)** sans modifier le comportement de Judy ni le schéma métier.

## Changements

- remplacement de l'ancien symbole de splash par le logo animé VSNT **Concept 03 v7** fourni ;
- géométrie SVG reprise du handoff de référence : sphère centrale, deux mains concentriques, arc extérieur et halo final ;
- animation rejouée à chaque splash et à chaque prévisualisation ;
- conservation des quatre styles de splash existants avec recoloration du logo :
  - Classique : ambre / ivoire ;
  - Wallace / Joi : or / ivoire ;
  - Minimaliste : blanc froid / cyan ;
  - Cyberpunk : rouge / cyan ;
- le splash reste affiché au minimum jusqu'à la fin de l'animation VSNT et, si le MP3 est plus long, jusqu'à la fin du MP3 ;
- page **À propos** : utilisation du logo complet orange sur fond noir fourni ;
- slogan définitif aligné sur le visuel fourni : **Connecting Minds & Bytes** ;
- icône Android remplacée par le symbole blanc VSNT ;
- fonds des icônes legacy/adaptive configurés transparents ;
- ajout des ressources launcher mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi + adaptive v26/v33 ;
- conservation des sources de branding dans `assets/branding`.

## Données

Aucune migration : le schéma reste `3100`.
