# Holophone™

Holophone™ is an open-source Android AI companion application developed by VSim NeuroTek (VSNT).

 Connecting Mind & Bytes.

Holophone is an experimental Android application designed around a persistent AI companion, with conversations, voice interaction, memory, media features and a cyberpunk-inspired interface.

## Current version

Holophone 3.1.4

## Main features

- AI-powered conversations
- Persistent companion memory
- Voice conversations
- ElevenLabs voice synthesis support
- Gemini AI integration
- Emotional avatars
- Image and media sharing
- Spotify-related features
- Custom Holophone keyboard
- Android immersive interface
- Local data management and backups
- Configurable companion personality

## API keys

Holophone does not include API keys.

Users must provide their own credentials from the application settings for the services they want to use, such as

- Google Gemini
- ElevenLabs

Never publish your API keys or Android signing credentials.

## Installation

Holophone is distributed as an Android APK outside the Google Play Store.

Pre-built APK releases will be available in the Releases section of this repository.

Android may ask you to authorize installation from unknown sources when installing the APK.

## Building from source

The repository contains the Android project, web application sources and Windows scripts used to prepare and build Holophone.

More detailed build instructions will be added progressively.

## Project status

Holophone is an experimental personal project under active development.

Expect changes, incomplete features and occasional bugs.
