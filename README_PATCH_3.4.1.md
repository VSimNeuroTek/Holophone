# Holophone 3.4.1

Release technique centrée sur la sauvegarde globale et l audit des réglages.

1. Fermer Android Studio.
2. Lancer `APPLIQUER_PATCH_3.4.1.cmd`.
3. Lancer `RELEASE_3.4.1.cmd` depuis le projet Holophone.
4. Générer l APK release signé avec le keystore existant.

La sauvegarde globale est écrite dans `Documents/Holophone/saves`.
