# Holophone patch 3.2.3

Correctif cumulatif de présentation pour Holophone 3.1.4 / 3.2.0 / 3.2.1 / 3.2.2.

## Contenu

- toute la Continuité vivante 3.2.x conservée ;
- fiche système VSNT bilingue conservée ;
- logo `À propos` désormais centré dans un bandeau fixe ;
- taille cible du logo : 114 × 114 CSS px (~3 × 3 cm) ;
- titre `À PROPOS` / `ABOUT` centré juste sous le logo ;
- drapeaux 🇫🇷 / 🇬🇧 agrandis à 48 × 34 px ;
- ancien dock latéral 76 px supprimé ;
- aucune migration de données supplémentaire.

## Installation

1. Fermer Android Studio.
2. Lancer `APPLIQUER_PATCH_3.2.3.cmd`.
3. Depuis le projet Holophone, lancer `RELEASE_3.2.3.cmd`.
4. Générer ensuite l'APK signé `release` dans Android Studio avec le keystore existant.

Version : `3.2.3` — `versionCode 50` — schéma `3200`.
