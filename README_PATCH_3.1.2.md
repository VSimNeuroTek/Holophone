# Holophone — patch 3.1.2

**Objet :** branding VSNT définitif, logo animé sur les quatre splash screens, logo complet dans À propos et nouvelle icône Android transparente.

## Installation

1. Fermer Android Studio.
2. Extraire cette archive.
3. Lancer `APPLIQUER_PATCH_3.1.2.cmd`.
4. Lancer `RELEASE_3.1.2.cmd` depuis le projet Holophone.
5. Générer l'APK signé `release` avec le keystore existant.

Version : `3.1.2` — `versionCode 44` — schéma de données `3100`.

Le patch sauvegarde les fichiers remplacés dans `_backup_patch_3.1.2`.
