# Holophone 3.2.1 — VSNT System Profile

## Objectif

Cette version ne change pas le comportement de la Persona. Elle refond entièrement la page **À propos** pour l'aligner avec le niveau de finition et l'identité technologique actuelle de Holophone.

## Nouvelle page À propos

L'ancienne présentation légère (« Un téléphone de fiction », « Comment ça marche ») est remplacée par une fiche système VSNT plus crédible et plus cohérente avec le produit.

La page présente désormais :

- **VSim NeuroTek (VSNT)** ;
- division fictive **Synthetic Presence Systems** ;
- **Holophone™ · Adaptive Persona Interface** ;
- les axes **Persistent Persona**, **Temporal Continuity**, **Local-First** et **Multimodal Runtime** ;
- six modules techniques : Persona Runtime, Memory Fabric, Temporal Engine, Interaction Layer, Initiative Core et Privacy Architecture ;
- une description précise du modèle local-first et des transmissions nécessaires aux fournisseurs externes ;
- la règle qu'aucune clé de service n'est intégrée dans l'application distribuée.

Le logo VSNT orange/noir validé reste inchangé et n'est pas recoloré par les thèmes. Le reste de la page utilise les variables de thème Holophone.
